# مشروع نظام منير (Milyar System)

نظام مؤتمت لتوثيق وإدارة البرمجيات والأنظمة المستندة إلى معايير صارمة للسلامة الرقمية والتحقق من سلامة البيانات المرجعية.

## الهيكل الإداري والقيادي للمشروع
* **القائد البيولوجي والعصبي للنظام:** منير محمد نذير سنجاب.
* **المرجعية البرمجية:** يُدار النظام عبر Copy/Paste المباشر إلى بيئة العمل المخصصة في (Termux).

## نظام حماية سلامة القرآن الكريم (Quran Guard & Integrity)
يحتوي النظام على آلية حماية مشددة على مستوى البايت (Byte-Level Integrity) تمنع التلاعب بالنص المرجعي أو تعديله بالخطأ أثناء العمليات البرمجية أو عمليات التعلم البرمجي.

### المكونات الحالية:
* `quran_integrity_check.py`: السكريبت المطور لحساب البصمة الرقمية ومطابقة مصفوفة المعايير الثلاثية (عدد الأسطر، عدد الكلمات، وعدد الحروف) دون فك أو تعديل تشكيل النص.
* `quran/quran_integrity_manifest.json`: ملف البيان المرجعي الموثق والمغلق الذي يحتوي على بصمة `SHA-256` لخط الأساس والمقاييس البنيوية للنص.
* `.git/hooks/pre-commit`: خطاف محلي مؤتمت (Hook) مدمج بـ Git لحظر أي عملية تثبيت (Commit) في حال حدوث أدنى تغيير في بايتات الملف المرجعي.

## معايير الفحص والمطابقة
عند كل عملية تثبيت، يقوم النظام بالتحقق الآلي من:
1. تطابق البصمة الرقمية `SHA-256` بنسبة 100%.
2. ثبات عدد الأسطر البنيوية (`line_count`).
3. ثبات عدد الكلمات وحجم البايتات الشامل (`word_count` & `byte_length`).
4. عدم السماح بالاستبدال التلقائي أو التعديل البشري لملفات الحظر دون مراجعة معزولة بالكامل.
