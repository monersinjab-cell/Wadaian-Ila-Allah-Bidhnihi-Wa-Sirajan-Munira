# 📖 دليل المساهمة البرمجي الموحد — منظومة المليار

مرحباً بك في مشروع **«وداعياً إلى الله بإذنه وسراجاً منيراً»**. لضمان سلامة وموثوقية المنظومة، تخضع جميع المساهمات (البشرية والآلية) للقواعد الصارمة التالية:

## 🛑 القواعد القطعية غير القابلة للنقاش
1. **القرآن هو القرآن:** يُمنع منعاً باتاً تعديل نصوص القرآن العظيم أو توليد آيات أو إسقاط علامات التشكيل أو الوقف.
2. **الفصل التام:** يجب الفصل البرمجي والمرئي المطلق بين النص القرآني الصريح، والتفسير المأثور، ومخرجات الذكاء الاصطناعي، والفرضيات العلمية.
3. **الحظر الميكانيكي:** لا تُقبل أي بوابة حوار أو نموذج إضافي ما لم يمر مخرجه إجبارياً عبر دالة التحقق الحتمي `verify_and_isolate_output` ومطابقتها للمرجع بنسبة 100%.
4. **سلامة المصدر:** يجب التحقق التشفيري (SHA-256) من سلامة ملفات البذور قبل الإقلاع.
5. **الصدق الرقمي:** يُمنع الادعاء بنجاح أي اختبار أو تدريب أو إنجاز قبل حدوثه الفعلي وظهوره في مخرجات الطرفية.
